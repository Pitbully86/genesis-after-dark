# Genesis After Dark

## Studio walkthrough

`site/studio/index.html` is an interactive 3D model of the studio set. You can orbit or walk
around it, look through Camera 1, Camera 2 and the iPhone wide shot, switch the lights on
and off, and read measured distances for every light, camera and mic.

To view it locally, open the file in a browser. `.github/workflows/pages.yml` publishes `site/` to
GitHub Pages on every push to `main` (set Settings → Pages → Source to "GitHub Actions").
